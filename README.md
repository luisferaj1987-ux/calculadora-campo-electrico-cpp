# ⚡ Electric Field Calculator / Calculadora de Campo Eléctrico

A C++ scientific CLI tool for physics calculations, focusing on automatic solving, unit conversions, and isolation operations for electric fields, forces, and point charges.
*Herramienta de consola en C++ orientada a la física computacional para el cálculo y despeje automático de campos eléctricos, fuerzas y cargas, incluyendo conversiones de unidades.*
